# VB.NET — estudo extra

Esta versão foi feita apenas por curiosidade e para comparar o desenvolvimento em VB.NET com o VB6. **Não faz parte dos exercícios solicitados e não substitui o projeto da pasta `01-vb6`.**

Requer .NET SDK 10 com Windows Forms. Abra `desafio-tec-vbnet.slnx` ou execute, na raiz do repositório:

```powershell
dotnet run --project extras/vbnet/desafio-tec-vbnet.vbproj
```

Use a API de `01-vb6/API` e ajuste a URL da tela para `http://127.0.0.1:3000/produtos`.
